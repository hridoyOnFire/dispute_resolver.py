# GenLayer AI Dispute Resolver Protocol

A decentralized application (dApp) built on **GenLayer Intelligent Contracts** to automate dispute resolutions using LLMs and decentralized consensus.

## 🚀 Features
- **Intelligent Contract**: Driven by `dispute_resolver.py` written in Python.
- **On-Chain AI Decisioning**: Evaluates claims and evidence automatically.
- **Full Stack Integration**: Complete frontend dashboard with a Flask backend.

## 🛠 Tech Stack
- **Smart Contract**: GenLayer Python SDK
- **Backend**: Python (Flask)
- **Frontend**: HTML5, JavaScript, Bootstrap 5
